# Ideas set aside

The first version uses the "Särkänniemi rides + festival night" theme for what Indy climbs on.
These other themes were considered and may come back as alternative levels or unlocks:

- **Renovation.** The tower is wrapped in scaffolding, hoists and window-cleaning gondolas: the facade renovation
  from the first game has followed Indy here.
- **Dream cat tree.** Indy dozes on his windowsill looking at the tower and dreams it into a giant cat tree:
  sisal-wrapped shaft, carpeted shelves, dangling toy mice, yarn balls, cushions.
- **Winter.** A frozen tower with snow ledges, icicles and ice-crusted cables.
